## 三、前端面板（新壳）

### ⑥ 生活事件场景页

- 入口：首页 →「生活事件」卡（1 步）
- 能做什么：7 条原型（预算锁定 / 定期出资 / 出行保障 / 大额凑集 / 失卡止损 / 阶段盘点 / 分摊收款）+ 3 条组合入口 + 我的记录；L1 步骤条为 ①冻结预算 → ②下单结算 → ③解冻余额，每步显示金额与状态
- 五态：`scene-life-{entry,data,empty,loading,error}.png`
- 边界：原型只组装链路，不改动作序列与三色判定（判定归 `policy/pdp`）；缺槽一律追问，不猜金额与卡片

### 记录页 5 个 tab

- `transfers`（转账）/ `holdings`（持仓）/ `cards`（卡片）/ `suspicions`（可疑）/ `charges`（扣款），入口按钮与 tab 一一对应
- 每 tab 都有空 / 加载 / 失败 + 重试；无来源字段如实显示「—」，前端不编造
- 证据：`records-framework-data.png`、`records-framework-error.png`、`records-audit.png`

### 壳与身份

- 对话空态补三色口径：绿＝仅自动查询 / 黄＝由您确认 / 红＝需要强验证
- 侧栏头像取登录用户姓名首字；未登录保留占位并标「演示」
- PWA：`manifest.json` 安装入口 + `btn-install` / `install-status`，`sw.js` 显式 `Service-Worker-Allowed: /`，API 明确不进 Cache Storage
