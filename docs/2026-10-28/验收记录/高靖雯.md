## 1. 前端三件（今天的主交付）

### 1.1 场景页「额度卡」（新增）

- 位置：场景页 → 转账 → 第一张卡「今日转账额度」（`#quota-panel` / `#quota-status` / `#quota-body`）。
- 数据：`GET /api/options` 新增只读 `quota` 字段，**前端不计算**：
  - `daily_limit_cents` = `min(DAILY_LIMIT_YUAN*100, gateway.daily_transfer_limit(user))`
  - `daily_accumulated_cents` = `gateway.daily_transfer_total(user, today)`
- 实测（8013，先做一笔 500 元转账后）：

  | 元素 | 实际显示 |
  |---|---|
  | 卡头小字 | `业务日 2026-10-01 · 额度与已用均读服务端` |
  | 额度行 | `本人日限额 ¥1000.00 · 已用 ¥500.00 · 剩余 ¥500.00` |
  | 进度条 | 蓝色填充约 50%（`.bill__bar-track`，宽度 = 服务端数字算出的百分比） |
  | 说明行 | `已用 50%。超过日限额的转账按红色（需强验证）处理；这里不在前端计算任何数字。` |
  | 超额分支 | 已用 > 限额时整行按 `.quota--over` 变红并写「已超额」，不出现负数（单测覆盖） |
