## 5. 失败归因、改链路和复跑闭环

| 发现 | 归因环节 | 调整 | 复跑结果 |
|---|---|---|---|
| 回放状态在完整凭据环境下误报 adapter | 渠道模式判定 | replay 开关优先，健康页如实显示 replay | 回放健康状态正确 |
| 重放事件可能绕过外部身份复核 | 身份映射 / 幂等 | 返回缓存响应前再次校验 open_id → user_id | 解绑后重放返回 401 |
| 渠道审计用户可能串用 | 审计写入 | 分发器显式传递当前 user_id | 多用户隔离测试通过 |
| 已取消订阅仍出现在 upcoming charges | 计划生成 | 过滤 cancelled 状态 | 取消后查询不再列出该扣款 |
| 飞书出站响应只看 HTTP 200 | 执行/回执 | 同时要求响应 JSON code == 0 | 非零业务码按发送失败处理 |
