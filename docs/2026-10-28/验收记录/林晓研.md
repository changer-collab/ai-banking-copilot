## 三、前端面板（新壳）

### ② 账单场景页

- 入口：首页 → 「账单分析」卡（1 步）
- 能做什么：看本期异常计数 / 可疑前 3（置信度 + 免责）/ 用户画像（消费结构·订阅负担·大额风险）/ 近 6 月支出趋势（SVG）/ 分类占比 / 异常类型计数 / 展开明细表 / 去记录页

### ④ 卡片场景页

- 入口：首页 → 「卡片管理」卡（1 步）
- 能做什么：卡号 / 类型 / 状态 chip / 日限额；锁卡、补虚拟卡可直接发起；挂失 / 解锁 / 调额为红色动作**灰显**并写明「需强验证，去对话办理」；状态分布 + 日限额上限条
- 空：`暂无卡片`；加载：`正在读取卡片…`；失败：`卡片读取失败，请检查网络后重试。` + 重试
- 截图：`scene-cards-{entry,data,empty,loading,error}.png`

### 记录页两个 tab

- 可疑清单：可疑类型 / 状态 / 置信度 / 影响金额 / 证据（日期时间 · 城市 · 商户）/ 渠道 + 免责说明

- 有数据：`records-suspicions-data.png`、`records-cards-data.png`；空态：`records-suspicions-empty.png`、`records-cards-empty.png`
