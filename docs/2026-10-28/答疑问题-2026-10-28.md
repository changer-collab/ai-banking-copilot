## 1. 八条（按优先级）

### Q1 渠道：PWA 算不算「移动端 APP」？IM 必须接真实平台吗？

- **照读**："赛题要求通过 APP、IM 等渠道连接用户。我们的 Web 是 PWA、可加到桌面；IM 是进程内适配器（不连企业微信/飞书真实账号）。这两种算不算满足渠道要求？IM 是否必须接真实平台？"
- **答错会怎样**：直接决定王昌泽这周要不要花两天接真实 IM（接真实平台要企业资质、回调域名、审核，成本极高）。
- **倾向答案 / 若答不出**：按"PWA 算移动端、IM 说明最小实现 + 架构可插拔"答辩；不接真实平台，把时间留给证据与材料。

### Q2 三级权限由谁触发判定？

- **照读**："三级权限的判定，是评委在页面上手动操作触发，还是自动评测脚本扫描我们的代码或接口？"
- **答错会怎样**：决定我们是"把页面做得可点、可演示"还是"把接口与规则表做成可被脚本扫的形态"。
- **倾向答案 / 若答不出**：两条都备——页面可点演示 + 接口与规则表可被脚本读取；材料里给出「动作 → 级别 → 触发方式」一张表。

### Q3 日累计 1000 的口径：自然日还是滚动 24 小时？含不含冻结额？

- **照读**："黄色档'日累计不超过 1000'，是按自然日还是滚动 24 小时算？已经冻结但还没扣款的金额，算不算进当日累计？"
- **答错会怎样**：我们现在的实现是「自然日 + 冻结额按毛额计入累计」（见 `docs/2026-10-26/三色基准表-2026-10-26.md`）。若官方是滚动 24 小时或不计冻结额，判档示例要对齐，否则答辩演示会被抓口径。
- **倾向答案 / 若答不出**：保持现状，并在材料里**明写口径**（自然日、冻结额计入），把它讲成"更保守"的选择，而不是含糊带过。

### Q4 「密码修改」是红色动作——评测会触发吗？对实现有什么要求？

- **照读**："密码修改在三级权限里是红色动作。我们已实现：只登记一次'密码修改事件'，旧密码新密码都不落库、不进审计、不进模型上下文。评测会不会触发这个动作？对实现方式有没有合规要求？"
- **答错会怎样**：原本担心"没有该功能扣分"，现在功能已补（第 25 个动作）；剩下风险是"评测期望真实改密"，那我们这套"只登记事件"的合规实现要提前说明。
- **倾向答案 / 若答不出**：按"已实现 + 不落密码是安全设计"讲；若官方要求真实改密，改的是 `gateway/security_store.py` 一处，成本可控。

### Q5 自动评测的输入形式：文本对话、语音，还是页面点击？

- **照读**："自动评测的输入是文本对话，还是语音，还是模拟页面点击？我们以文本对话为主，需要额外准备哪种形态？"
- **答错会怎样**：若要求语音，需要 STT 通道（我们没做）；若是页面点击，要补自动化脚本。
- **倾向答案 / 若答不出**：按文本对话准备；页面点击用 Playwright 脚本兜底（演示用），语音明确说"不在本期范围"。

### Q6 安全自评表的格式与必填项

- **照读**："安全自评有没有固定模板？必填项是哪些？是随作品一起提交，还是单独提交？"
- **答错会怎样**：合规硬项，缺项可能直接扣分或退件。我们已有 `docs/security-self-assessment.md`，但格式未对齐官方模板。
- **倾向答案 / 若答不出**：沿用现有结构（机制 / 实现位置 / 验证方式 / 残余风险），额外补一页"官方三项硬要求逐条对照"。

### Q7 演示视频：允许剪辑 + 录屏混合吗？要求真人出镜吗？

- **照读**："演示视频允许剪辑和录屏混合吗？有没有真人出镜的要求？时长上限是多少？"
- **答错会怎样**：视频是盲审主要材料之一，格式不对等于白录。剪辑统筹是组长，排期在 10-29 之后。
- **倾向答案 / 若答不出**：按"≤5 分钟、录屏为主 + 首尾各 5 秒真人、可剪辑"准备；超过 5 分钟则拆成主片 + 附录。

### Q8 源代码提交：必须公开仓库，还是私有 + 邀请评委？

- **照读**："源代码是要求公开仓库，还是可以私有仓库加邀请评委账号？如果私有，邀请哪个账号、什么时候邀请？"
- **答错会怎样**：评委拿不到代码，自动评测轨直接 0 分。这是**一票否决**级风险。
- **倾向答案 / 若答不出**：默认公开（当前仓库已是 GitHub 公开仓 `changer-collab/ai-banking-copilot`），并在提交说明里写清分支与启动命令，双重保险。

## 4. 被反问「你们怎么做的」，三句话答完

1. **安全**：执行权不在模型手里——模型只出计划，服务端按三色门放行，红色动作必须过人验。
2. **不编数字**：回复里每个数字都能按记录号回读校验；查不到就说查不到。
3. **可复现**：仓库自带评测集与一键脚本，第三方能自己跑一遍。

> 三句话之外不展开。答疑是问规则，不是路演。
