# 实施计划（`docs/plans/`）

本目录按模块拆分**可独立交付并验收**的实施计划。每份计划遵循统一约定：

- **TDD**：先写失败测试 → 跑测试确认失败 → 最小实现 → 跑测试确认通过 → 提交
- **验收门槛**：**跑通才算完成**（不接受"写完了但没跑"）
- **任务粒度**：每个 Step 是一个动作（2–5 分钟）
- **无占位符**：不写 TBD / TODO / "稍后补充"
