# 作品材料证据盘点 · 2026-11-02

本文件用于区分“代码已实现”“自动化测试覆盖”“单次现场实测”和“尚未接入”。它不是生产合规证明，也不替代完整测试报告。

## 证据等级

| 等级 | 含义 |
|---|---|
| A | 当前工作区有代码落点，并有对应自动化测试或确定性回归用例 |
| B | 有代码和测试，但测试只证明模拟核心银行/本地适配器，不证明外部系统 |
| C | 有一次或少量现场实测，不能外推到所有场景、模型版本或网络条件 |
| D | 未接入或没有当前可复现证据，材料必须作为原型边界披露 |

## 修改原则

1. 材料中的“已实现”限定为模拟核心银行或本地适配器范围。
2. 任何真实模型数字只记录实测输入、通道和结果，不从单次请求推导泛化率。
3. `R9`、`R14`、`R24`–`R28` 保持为公开披露的原型边界，不写“R1–R28 无未关闭风险”。
4. PPT、PPT 讲稿和视频脚本不在本轮修改范围内。
