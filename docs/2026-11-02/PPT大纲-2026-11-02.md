### 第 2 页 · 问题

- **任务**：40 秒把问题从「用户懒」改写成「银行不敢」。
- **版式**：左侧 35% 大数字；右侧 65% 三行失败模式；底部横贯转折句。
- **上屏逐字**：
  - 标题（23pt）：**7 步，还是 1 句话？**
  - 大数字（128pt，强调蓝）：**7**；旁边 30pt `步`
  - 数字说明（11pt 灰）：`手机银行完成一笔转账的` / `实际点击步数（我方实测）`
  - 三行：
    1. **会编造** → `事实零生成，数值只从网关取`
    2. **会被诱导** → `策略层按请求结构裁决，不读模型的话`
    3. **会越权** → `权限分级 + 计划级净效应，执行权不在 Agent 手里`
  - 转折条（24pt，白字，深蓝底）：**7 步变 1 句是效率问题；真正拦住银行的，是敢不敢把操作权交出去。**
  - 页脚（7.5pt）：`口径：现有手机银行页面实际点击路径；不含生物识别与后台处理。`
- **口播（40s）**：`先看一个数：我们自己量的，一笔转账 7 步。但真正拦住银行的不是 7 步，是三个失败模式：会编、会被诱导、会越权。这三个问题靠提示词解决不了，只能靠模型之外的确定性层。`

- **不做**：不引用行业「3 步以上」；不展开技术讲座。

### 第 4 页 · 架构（四盒）

- **任务**：55 秒解释「为什么模型不能直接动钱」。
- **版式**：四盒横排（每盒 2.65×3.00in，间距 0.16in），盒间 20pt `→`；底部锚点句。
- **四盒**：
  1. **意图层 / LLM 规划**：听懂模糊表达 / 拆 DAG / 出候选计划；交出 `候选计划 DAG`
  2. **审查层 / 独立模型·只审不改**：查遗漏动作 / 额外动作 / 否定表达；交出 `审查意见`
  3. **治理层 / 确定性策略**：权限分级 / 额度硬限 / 净效应 / 人工确认；交出 `绿 / 黄 / 红 裁决`
  4. **执行层 / 沙箱 + 审计**：隔离执行 / 全程留痕 / 回执为准；交出 `回执号 + 审计号`
- **锚点句**（22pt，白字，深蓝底）：**执行权不在任何 Agent 手里。**
- **图下小字**：`两个模型角色都只能提计划；只有 policy 层能说「可以」；28 个动作全部经同一 PDP。`
- **口播（55s）**：`四个盒子。上面两个都是模型：一个提计划，一个专门挑错，但都只能提案。真正说可以的是第三个盒子：确定性策略。最下面是执行和审计：只跑 28 个白名单动作，事实只从网关取。模型可以胡说，但它说的只是建议。`
- **答问**：Q 审查器多余？→ A 第二模型角色，只查错、不修改。
- **不做**：不讲模型选型；不画「AI 大脑」。

- **版式**：

  - 结论句（y 3.55，13pt）：`每个节点单独裁决，整条计划取最严 —— 一句话办几件事 ≠ 一次放行几件事。`

### 第 6 页 · 权限分级

- **任务**：65 秒证明三色是运行时算出来的。
- **版式**：左侧 2×2 四张输入卡；中间蓝色 PDP 条；右侧三出口；底部升档算式；本页不配手机图，红卡实景在 P8-B。
