## 二、旧 15 页逐页讲稿（原文，抽取自 `scripts/build_deck.py` 的 `notes()`）

> 保留原样的「口播」与「不要做」。**时间码与页序已失效**，只取文字。

### 旧页 01 → 新 1 · 封面

```
【15s｜0:00–0:15】封面。念主张，不念功能清单。
口播：『今天不讲我们做了多少个场景，只讲一件事——凭什么敢让 AI 动钱。』
不要做：不要念 6 个场景名，不要说『全场景智能体』。
```

### 旧页 02 → 新 2 · 问题（7 步）

```
【25s｜0:15–0:40】问题。先亮 7 步实测（我们自己量的，不替官方的『3 步以上』背书）。
口播：『7 步变 1 句是效率问题；但真正拦住银行的，是敢不敢把操作权交出去。』
不要做：不要展开行业大势，不超过 25 秒。
```

### 旧页 03 → 新 2 · 三个失败模式

```
【25s｜0:40–1:05】三个失败模式，一页一行，各配一句答案（下一页展开）。
口播：『这三条不是我们编的，是同类系统上线后反复出现的三处断点。』
不要做：不逐条展开原理，每条只给一句答案。
```

### 旧页 04 → 新 4 · 架构（**改为四盒，这段必须重写**）

```
【45s｜1:05–1:50】全 deck 最重要的一张图。手指着中间那层讲。
口播：『模型可以胡说，但它说的只是建议；真正有权说「可以」的，是中间这层确定性策略。』
不要做：不讲模型选型、不报算法指标、不展开三层各自的实现细节。
```

> **改法提示**：四盒版口播应加一句审查层——「第二个模型负责挑第一个模型的错，但它同样没有放行权；放行权只在确定性那层。」

### 旧页 05 → 新 4 · 四个技术点

```
【30s｜1:50–2:20】四个技术点不是四个炫技，是每层各守一处。
口播：『这四个点你随时可以让人翻代码，路径都在页面上。』
不要做：不念路径，不停留超过 30 秒。
```

### 旧页 06 → 新 5 · 生日链 DAG

```
【60s｜2:20–3:20】【Demo 1】讲一句，看计划卡出来。
口播：『一句话要动三个东西：冻一笔钱、下一单、把剩下的还回去。我们不是一次放行，是三次裁决。』
不要做：不承诺真实客户生日数据；不说这是「智能推荐」。
```

### 旧页 07 → 新 5 · 场景矩阵

```
【30s｜3:20–3:50】场景矩阵。不要念六个场景名，只念风险级别。
口播：『六个场景真正的差别不是功能，是最坏情况下它属于哪一级风险。』
不要做：不逐场景展开功能；不把这张表读成清单。
```

### 旧页 08 → 新 6 · 权限分级执行

```
【55s｜3:50–4:45】分级如何被执行。手指引擎框。
口播：『绿色不是「我们觉得安全」，是这次操作是纯查询；红色不是「我们觉得危险」，是日累计超了线。』
不要做：不复述赛题三色定义；不说「智能判断风险」。
```

### 旧页 09 → 新 6 · 升档实测

```
【40s｜4:45–5:25】【Demo 2】现场升红 + 挑战码。
口播：『同一张卡，第二笔就红了，不是因为我们更谨慎，是因为累计过了线。』
不要做：不宣称已接短信 / 人脸 / U 盾；不说「风控模型判断」。
```

### 旧页 10 → 新 7 · 五项机制

```
【55s｜5:25–6:20】【Demo 3】注入被拒 + 审计回查。
口播：『这五行不是五个独立开关，它们互相咬合：注入直接转人工，拒绝多了就熔断，全都在同一条审计链上。』
不要做：不逐条朗读技术文档；五行各指到一处就停。
```

### 旧页 11 → 新 8 · Demo A 顺畅闭环（**改为证据快照，口播要重写**）

```
【60s｜6:20–7:20】【Demo 4-A】顺畅闭环四步连演。
口播：『我什么都不点，就说一句话。』然后每步停 2 秒，最后点「查看记录」。
不要做：不解释架构；不在演示里改参数、不临时输入没排练过的句子。
```

> **改法提示**：改为「指着快照讲」——「这四张是我跑过的四段，每段都留着回执号和审计号，你现在就能核对。」

### 旧页 12 → 新 8 · Demo B 安全触发（同上）

```
【60s｜7:20–8:20】【Demo 4-B】四段对抗连演（35+40+35+40s，现场时间紧可退化为两段）。
口播：『接下来我故意让它做错事。』每段演完只报一句结果，不解释原理。
不要做：不美化失败；committed_unverified 必须如实说，不说「已全部撤回」。
```

### 旧页 13 → 新 11 · 边界

```
【35s｜8:20–8:55】边界。语速放慢，这是可信度最高的一页。
口播：『这几件我们没做，原因也讲清楚：它们不是做不了，是现在没到值得装上去的时候。』
不要做：不道歉、不含糊；不说「后续会补齐」这类空承诺。
```

### 旧页 14 → 新 12 · 路线与四个数字

```
【40s｜8:55–9:35】路线与数字。数字只报四个，不逐个解释。
口播：『我们先做透三个场景；换场景可以，换治理口径不行。』
不要做：不说「覆盖所有银行场景」；不报没有复跑命令的数字。
```

### 旧页 15 → 新 12 · 尾卡

```
【10s｜9:35–9:45】尾卡。停在这里等提问，不要继续讲。
```
