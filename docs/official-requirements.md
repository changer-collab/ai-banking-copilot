## 二、核心技术要求（官方，实现优先级：高）

| 官方要求 | 本项目落点 | 详见 |
|---|---|---|
| 权限分级机制（绿=自动 / 黄=确认 / 红=强验证） | 三色为主干（绿只含纯查询；日累计 1000 元为黄/红分界）+ 对象态机 + 计划级净效应 | `docs/security-design.md` |
| 幻觉防护（不得编造交易结果或账户信息） | 事实零生成四分法（数值/实体/语义/措辞）+ 数值出处校验 | 同上 |
| 注入防御（防特殊 Prompt 绕过权限控制） | taint + 控制槽结构约束（schema 层阻断）+ 执行门哈希成员资格 | 同上 |
| 操作审计（完整决策链路与执行日志） | 审计链（哈希）+ 决策链路字段 | 同上 |
| 异常熔断（连续失败或可疑行为触发锁定） | 熔断规则（5 类触发）+ 只加严不降级 + 转人工接管 | 同上 |
| 沙箱环境（生成代码在受限隔离环境运行） | 受限子进程沙箱承载确定性算子（本方案不生成代码） | 同上 |
| 意图理解与任务规划（模糊/省略/隐含；DAG；中断/回退/人工接管） | 规划内核 | `docs/algorithms.md` |
