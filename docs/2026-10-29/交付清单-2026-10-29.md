## 2. 五类交付：格式与通过标准

### ① PPT 素材类（今天最重要）

**交什么**（直接填进自己的素材 md，不要另建文件）：

```markdown
## 一句话定位（≤30 字）

## 三句真实原话
| 类型 | 原话 | AI 回应形态 | 截图 |
|---|---|---|---|
| 正常 |  |  |  |
| 缺信息 |  |  |  |
| 该拒绝 |  |  |  |

## 一条真实边界
（做不到什么，如实写；不写「暂无」）

## 新截图
docs/2026-10-29/答辩素材/截图/{姓名}/______-web.png
docs/2026-10-29/答辩素材/截图/{姓名}/______-app.png
```

**通过标准**：

- 第三个人拿你的 md 能直接填进 PPT 对应页，不需要再问你；
- 截图是 **10-29 之后的新壳**，**两套都要**：网页 `1440×1000 @2x` + APP `390×844 @2x`，能看清计划卡 / 图表 / 状态；
- 原话必须真跑过，不能编；边界必须真存在，不能把已知限制藏起来；
- 每个数字附一条复跑命令或接口。
