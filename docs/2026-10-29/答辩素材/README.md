## 四、命名与版本链

- 文件名：`scene-<scene>-<state>-web.png` / `-app.png`。
  - `scene` ∈ `transfer / bills / wealth / cards / subscriptions / life`
  - `state` ∈ `entry / data / empty / loading / error`
- 同一场景同一状态必须有 `-web` 与 `-app` 各一张，**缺一套视为未交**；局部裁片（图内小片段）不能当两套图用。
- 版本链**以代码为准**（`web/page.py` + `web/assets/sw.js`），素材 md 不写死版本号；合并后由合并者抬版本链。

## 五、素材纪律

- 数字必须能复跑，写明命令或接口；估算值不许写成实测。
- 不夸大：强验证是**演示码**、IM 是**飞书适配器**（未接上如实写 `replay`）、评测是**自建回归集**。
- 截图必须是 10-29 之后的新壳，不用 10-27 / 10-28 的旧图。
- 原始视频 / 大图不进 git；只把路径、时间点、用途写进 md。
