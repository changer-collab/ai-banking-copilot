## 一、每人必须回答的 9 个问题

1. **一句话定位**（≤30 字，评委听完能复述）
2. **用户痛点 + 3 句真实原话**：正常 / 缺信息 / 该拒绝，各一句
3. **PPT 一页**：标题 / 3 个要点 / 一张图或截图 / 一句结论
4. **视频 30 秒分镜**：输入 → AI 回应 → 确认或强验证 → 结果可查
5. **截图清单**（3–5 张，路径 + 用途）
   - 必含：场景页有数据（要有图表或明细表）+ AI 对话回答形态 + 操作可查；
   - 有图表就把图表拍进去；三态可以拼成一张图；
   - 图表用 CSS / SVG，不引入第三方库，数字必须来自接口。
6. **可量化证据**（1–3 个数字，必须能用命令复跑）
7. **技术亮点**（1–2 个，指到代码或测试文件）
8. **一个边界 / 失败案例**（如实写，证明不吹）
9. **评委可能追问 3 题 + 3 句话答案**

## 四、素材纪律

- 截图必须**新壳**（`workspace.css?v=12` / `app.js?v=28` / `sw.js?v=21`），不用 10-27 的旧图。
- 数字必须能复跑，写明命令或接口；估算值不许写成实测。
