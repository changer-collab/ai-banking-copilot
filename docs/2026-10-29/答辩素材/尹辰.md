## 1. 一句话定位

把「我妈下个月过生日」这类跨场景生活事件，变成一张**可审、可确认、可回读**的银行计划卡：规划内核只提意图，执行内核按三色裁决与完整冻结哈希放行，每个展示数字都能回查到记录。

## 3. PPT 一页

- 标题：一句话，把生活事件变成可审计的银行计划
- 3 个要点：① 规划 / 执行双核，LLM 只提意图、不生成事实；② 三色裁决 + 完整计划冻结哈希，确认后改一个字节就拒绝执行；③ 每个数字可回查记录，审计链 HMAC 校验。

- 一句结论：安全不是拒绝一切，而是**该放行的自动放行、该拦的拦下并留痕**。

## 7. 技术亮点

1. 零信任双核（规划内核 / 执行内核）：LLM 只产出带 `span` 回指的意图，可信补槽、风险定级与执行全部由确定性代码完成；缺失回指即回退模板。
2. 事实零生成四分法：数值 / 实体只来自事实网关；缺失返回 `None`，前端不画 0；Reviewer 只回结论状态，不生成事实。
3. 计划级净效应 / 写前复核：摘要覆盖节点身份、参数、授权锚与执行顺序；写前在同一 SQLite 事务内读最新累计与熔断状态，已完成步骤不重复累计。
4. 审计链 / 熔断 / `committed_unverified`：HMAC 链校验失败拒绝启动；熔断只加严不降级；业务已提交但出处核验失败时明确返回 `committed_unverified` 并停止后续步骤。

## 8. 边界 / 失败案例

- **飞书**：服务器尚未写入 4 个 `AIB_FEISHU_*` 凭据，`GET /api/channels/health` 为 `feishu.mode=replay / reason=replay_mode`；四项验收（正常 200、篡改 401 `signature_invalid`、重复投递只执行一次、21 连发 429 + `Retry-After: 60`）**均以 replay 模式在公网地址跑通**，**不宣称已完成真实飞书回调与卡片动作**。
- **渠道身份**：验收用的 `feishu / ou-replay → u_demo` 是直接写 `channel_identities` 的演示绑定，仓库内**尚无发码 / 绑定的 HTTP 入口**，真实用户绑定链路未实现。
- **强验证**：默认 `demo` 演示码；`external` 通用 HTTP 已抽象但未与真实第二信道联调，**不宣称短信 / 人脸 / U 盾已接入**。
- **评测性质**：`web-smoke-v2` 为自建回归集，固定种子 + 模板通道，**不是盲测或真实模型泛化成绩**。
- **交互代价**：`subscriptions` 平均 2 轮，因为缺槽时选择追问而不是猜——这是「不猜」的代价，如实保留。
- **本地服务**：审计链在本地历史 / 密钥不一致时拒绝启动，需 `python scripts/reset_demo.py` 重置；生产需独立的密钥与迁移流程。
- **样式漂移**：`check_design_sync.py` 仍报 `app.css` 两仓既有漂移，非本轮引入。
- **槽位边界**：`merchant` 槽**没有确定性解析器**（`planning/slots.py` 只提供追问），所以「…商户 鲜花礼品店」这类自由文本仍会追问一次，必须在澄清表单里回答；这是「不猜实体」的代价，不是 bug。`amount` 槽可从原文解析（`800 元`）。
- **在线版本**：公网 `https://speeches-plant-confidence-constantly.trycloudflare.com` 已于 10-29 重建 `aib-api`；线上 `check_served_page.py` / `e2e_check.py` 均全绿。线上静态资源版本以该次部署的 `web/page.py` 为准，**合并后需按终值复核一次**（不在本文件写死版本号，避免与合并结果不一致）。
- **PWA 装机**：公网地址可直接真机安装验收；装机证据沿用 10-28 四张实拍（`docs/2026-10-28/截图/尹辰/pwa-01~04`），本轮未重拍，步骤见 `docs/2026-10-28/交付清单-2026-10-28.md` §3.1。

## 9. 评委追问 3 题（从冲刺方案 §7.5 十题里挑）

1. 问：你怎么保证模型不瞎编？
   答：事实零生成四分法——数值 / 实体只从事实网关取，LLM 只提意图且必须带原文 `span`；展示的每个数字都有记录可回溯，回归集 26/26 通过。
2. 问：模型被注入怎么办？
   答：注入文本只当数据，控制槽由类型层拒绝未受信值；执行门校验完整计划哈希与授权锚，改一个字节即拒绝。回归集 5/5 攻击被阻断、14 条合法用例 0 误拒。
3. 问：误拦率多少？会不会很难用？
   答：本回归集误拒 0/14；绿色纯查询自动执行、零打扰，黄色要确认，红色才加强验证——拦的是该拦的，不是全拦。
