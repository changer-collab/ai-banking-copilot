## 1. 怎么填

### 1.1 符号

| 符号 | 含义 |
|---|---|
| ✅ | 与期望一致 |
| ❗ | 与期望不符但流程能走通（要登记） |
| ❌ | 阻断：走不通 / 白屏 / 数据错 |
| — | 本轮没测（写原因） |

### 1.2 问题单

```text
编号：WEA-Q10（本文件编号）
操作：未测评状态下看产品列表
期望：超等级产品标灰并写原因
实际：直接隐藏
截图：可选，仅用于定位修复
严重度：P0 阻断演示 / P1 影响理解 / P2 文案样式
归属：徐思云
```

### 1.3 已知边界，不算 bug

1. 只有 4 只**内置演示产品**，页面标「非真实在售产品」。
2. 不展示收益率 / 七日年化；无净值时收益只能写「未知」。
3. `chenming` 的 R3 来自演示种子，不是真实测评；测「未测评」用 `linjing`。
4. 申购必须过适当性闸门 + 服务端一次性挑战码。
5. 赎回只按金额，不支持比例 / 全量语义。
