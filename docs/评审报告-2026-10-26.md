## 4. 缺失清单（按致命度排序）

### P0 · 现在不补就会丢分 / 现场翻车

1. **零答辩材料**：无 PPT、无视频、无演示脚本。盲审只读材料，自动评测只跑代码，**1562 个测试不产生任何分数**。
2. **零量化证据**：`run_benchmark.py` 已能输出 `scenario_task_success_rates` 等汇总，但从未产出公开结果。评委无法验证"安全不等于拒绝一切"。
3. **零竞品/对标**：评审口径明确含"竞品分析"。可直接复用恢复出的《参赛对标与改进方向》三方对比表与两条公开基准数字。
4. **演示脆弱性**：演示库无重置；当日大额转账会让后续卡片合法升红；无 `AIB_DISABLE_LLM=1` 离线兜底演练；无录屏备份。
5. **渠道硬缺口**：APP 无实现、IM 未接平台。需在 10.28 确认口径，或本周补移动端 PWA / 最小真 IM。

### P1 · 影响创新与深度分

6. **AI 标签**：现场默认走模板通道、Reviewer 旁路；建议演示强制 `llm-strict` 链路 + 三角色（规划/审查/规则风险官）可视化 + 量化审查拦截率。
7. **风险评估闭环**：补测评问卷 → 风险等级 → 适当性匹配解释，形成场景③完整链路。
8. **跨场景资金锁定**：把生日链路接上 `funds.freeze`（冻结预算 → 下单 → 结算/释放），对齐赛题示例。
9. **叙事缺口**：补"普惠"（让不熟悉 App 的人一句话安全办理）与"数据边界声明"（零外呼、只读网关）。

### P2 · 加分项

10. 架构图补 PNG/SVG；作品简介补"三段结构"（技术创新 / 场景落地 / 价值创造）。
11. 冻结 `v1.0-submission` tag；决定 `wt-data` 分支去留；把恢复的对标文档归档。
12. README 加 CI 徽章或最近一次全绿记录；把"意图克制 / 不过度相信用户断言 / 可解释性 / 可审计"四个标签显式命名并指到代码位置。

## 6. 10.28 线上答疑问题清单（逐条照问）

1. 自动评测是对**代码仓库**跑，还是对**线上部署服务**跑？有无固定入口（HTTP 端点 / CLI / 镜像）与输入输出格式？
2. 是否提供**公开评测集或样例集**？评分维度与权重是否公开？
3. 六场景中自动评测覆盖哪几个？"至少 3 个"如何验证？
4. 提交物清单以哪个页面为准？PPT / 视频在 11.02 是否必需？
5. **APP 渠道的认定口径**：PWA / 响应式 Web 是否算 APP？IM 是否必须接真实平台？
6. 场景③"风险评估"是否要求完整测评问卷，还是允许"受信任测评事实 + 适当性拒绝"？
7. 场景⑥是否必须体现"锁定资金"？仅演示下单是否可接受？
8. 48h 黑客松是"在现有作品上优化"还是现场新题？是否允许带本地代码/依赖？
