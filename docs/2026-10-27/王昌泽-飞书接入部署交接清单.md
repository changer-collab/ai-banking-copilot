## 组长部署步骤

### 1. 合并代码

合并 [PR #14](https://github.com/changer-collab/ai-banking-copilot/pull/14) 到 `sprint/1026`。

服务器只从 `sprint/1026` 部署，不从 `main` 部署。

### 2. 打包并上传

```bash
git checkout sprint/1026
git pull origin sprint/1026
git archive --format=tar.gz -o aib.tar.gz sprint/1026
scp aib.tar.gz aistock@121.37.46.229:/home/aistock/
```

### 3. 更新服务器应用

只操作 `aib-api-1` 和 `aib-tunnel`，不要影响 `expert-managementsystem-*`、`qq_*`、`komari` 等其他服务。

```bash
ssh aistock@121.37.46.229
cd ~/aib

rm -rf src docs tests scripts deploy Dockerfile docker-compose.yml pyproject.toml
tar -xzf ~/aib.tar.gz -C ~/aib

API_HOST_PORT=18080 \
PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
docker compose -p aib up -d --build
```

不要重启 `aib-tunnel`，否则 quick tunnel 地址可能变化。

### 4. 写入飞书凭据

凭据只私下写入服务器 `.env`，不要写入仓库、文档、截图或群聊：

```text
AIB_FEISHU_APP_ID=...
AIB_FEISHU_APP_SECRET=...
AIB_FEISHU_VERIFICATION_TOKEN=...
AIB_FEISHU_ENCRYPT_KEY=...
```

写入后重新执行应用构建命令：

```bash
API_HOST_PORT=18080 \
PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
docker compose -p aib up -d --build
```

### 5. 服务器本机验收

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:18080/
curl -s http://127.0.0.1:18080/api/channels/health
curl -s -X POST http://127.0.0.1:18080/api/im/message \
  -H 'Content-Type: application/json' \
  -d '{"text":"查余额"}'
```

健康接口必须包含：

```json
{
  "feishu": {
    "configured": true,
    "mode": "adapter"
  }
}
```

### 6. 飞书后台配置

确认健康接口已经是 `adapter` 后，在飞书开放平台执行：

1. 请求地址填写：
   `https://speeches-plant-confidence-constantly.trycloudflare.com/api/im/feishu`
2. 保存请求地址。
3. 订阅事件 `im.message.receive_v1`。
4. 保存应用配置。

### 7. 真实回调验收

- 正常消息：返回计划卡。
- 篡改签名：返回 `401`。
- 同一个 `event_id` 重放：只执行一次。
- 超过限流：返回 `429` 和 `Retry-After`。
- 飞书发起的消息与网页相同输入：比对 `state`、三色等级和 `card_id` 结构。
- 未绑定的飞书身份继续返回 `401`。

回放身份沿用绑定表：验收库预置 `ou-replay` 到当前用户；未绑定身份不绕过校验。
