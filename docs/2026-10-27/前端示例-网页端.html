两个位置先记住（之前说错过，以这里为准）：
  • 场景功能页＝左侧导航「场景」里的某一项（首页 / 转账 / 账单 / 理财 / 卡片 / 订阅 / 生活事件），里面只放该场景的原生功能（额度 / 收款人 / 产品 / 卡片 / 持仓…）。
  • 对话页＝左侧导航「场景」下方的「对话」，是一个独立页面：整页只有会话——左列会话列表（可「新建对话」、可切换）+ 右列消息流 + 输入框。它不和场景功能混在一起。
  • 对话页的空态照参考图做：居中 AI 图标 + 「从一句话开始」+ 说明 + 一排预设快捷消息 + 三色口径小字。

渠道 ≠ 网页里的一个聊天页。
  • 赛题原文是「用户可通过 APP、IM 等渠道与 Agent 联通」——意思是飞书 / 微信（微信较难，可弃）这类 IM 直接连到我们的后端，消息在飞书里收发，不在网页里另造一个「渠道消息」页。
  • 网页里与渠道相关的只有渠道健康页（看三个渠道通不通、限流多少、是否 replay 模式），这是运维/答辩用的页面，保留。
  • 后端 GET /im 只是本地联调用的极简页（本机不装飞书也能走一遍「文本进 / 计划卡出」），它不算产品页面，不参与前端验收。

通用施工要点（网页端 · 照这 13 条做）

与分工文档 §5.0 一一对应；蓝色角标是重点标注。

  1. 入口：每个场景在首页或左侧导航点得进去（含空状态）。入口与导航统一由一处增删。
  2. 场景功能页 = 左侧「场景」里的那一项：只放该场景的原生功能（额度 / 收款人 / 产品 / 卡片 / 持仓…）。这一页不放聊天。
  3. 对话页 = 左侧「场景」下方新增的「对话」：独立页面，整页只有会话——左列会话列表（可「新建对话」、可切换历史会话）+ 右列消息流 + 输入框；不和场景功能杂糅在一起。
  4. 对话空态照参考图：居中 AI 图标 + 「从一句话开始」+ 两行说明 + 一排预设快捷消息 + 三色口径小字（绿＝仅自动查询 / 黄＝由您确认 / 红＝需要强验证）。
  5. 预设快捷消息（网页 / APP 都要有）：3–5 条贴近真实业务的句子，如「转给李娜 500 元」「查一下上月账单」「查余额」；点一下直接发出去，别写「示例 1 / 测试」。
  6. 计划卡：先给我看、再执行。步骤 + 余额轨迹 + card_id + frozen_hash + 确认按钮；红级要有强验证。
  7. 五种气泡形态：用户 / 机器人文字 / 追问卡 / 提示条（黄红）/ 回执。缺参数出追问卡，别让用户再打一句。
  8. 渠道口径：网页里不显示渠道聊天；渠道 = 飞书（微信可弃）直接连后端。网页里只保留 渠道健康页；GET /im 仅本地联调用，不算产品页。
  9. 红动作：必须有显式入口，可灰显但要写清「为什么不能点、点哪解锁」；执行前走强验证并解释原因。
  10. 可查：AI 说做过的操作页面上必须查得到（列表 + 详情 + 状态 + 审计）；记录表带「渠道」列，能看出飞书里办的事在网页也查得到。
  11. 头像 + 个人中心：侧栏左下角放头像，点击弹出个人中心（身份信息 / 登录方式与安全 / 通知 / 退出登录）。登录与身份绑定依赖后端，属 §5.5 尹辰这一摊。
  12. 三态齐：空 / 加载 / 失败。失败写人话（429 → 「发太快了，X 秒后再试」），不写 Error。
  13. 不造结论 + 零外链：等级、余额、卡状态、登录状态一律读后端；不引 CDN / 外链字体，静态壳沿用现库版本（aib-static-shell-v11）；跑完留截图 + 「我说了什么 / AI 回了什么」，放 docs/2026-10-27/验收记录-{姓名}.md。
