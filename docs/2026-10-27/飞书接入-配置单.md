# 飞书接入配置单

## 0. 现状（2026-10-29 线上实测）

`GET /api/channels/health` 返回：

```json
{"channels":{"feishu":{"configured":false,"mode":"replay","reason":"replay_mode","card_action":false}}}
```

服务器 `~/aib` 是 tar 解包副本（无 `.git`）；容器内 `docker exec aib-api-1 env | grep AIB_FEISHU` **零输出**；
`channel_identities` 里只有一条 10-28 写进去的演示绑定 `feishu / ou-replay → u_demo`。
也就是说当前跑的是 **replay 模式**（回放密钥 + 回放事件），**不是真实飞书回调**。

## 1. 先改 `docker-compose.yml`（头号坑）

`environment:` 只列了 7 个 LLM / 日志变量，**不传任何 `AIB_FEISHU_*`**。只往 `.env` 写四个变量，容器里读不到，
health 会一直停在 `mode=replay`。在 `environment:` 末尾追加四行：

```yaml
      - AIB_FEISHU_APP_ID=${AIB_FEISHU_APP_ID:-}
      - AIB_FEISHU_APP_SECRET=${AIB_FEISHU_APP_SECRET:-}
      - AIB_FEISHU_VERIFICATION_TOKEN=${AIB_FEISHU_VERIFICATION_TOKEN:-}
      - AIB_FEISHU_ENCRYPT_KEY=${AIB_FEISHU_ENCRYPT_KEY:-}
```

## 2. 服务器 `~/aib/.env` 追加四个值

```text
AIB_FEISHU_APP_ID=<私发>
AIB_FEISHU_APP_SECRET=<私发>
AIB_FEISHU_VERIFICATION_TOKEN=<私发>
AIB_FEISHU_ENCRYPT_KEY=<私发>
```

**不要设** `AIB_FEISHU_REPLAY_MODE=true`——它会把 adapter 强制压回 replay。

判定逻辑在 `web/channels/feishu.py:76-109`：四个值**全部**非空 且 未显式开 replay，才 `configured=True`、`mode=adapter`。

## 3. 重建并校验

```bash
cd ~/aib
API_HOST_PORT=18080 PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
  docker compose -p aib up -d --build api
docker exec aib-api-1 env | grep AIB_FEISHU     # 应看到 4 行（值不打印到公网）
curl -s localhost:18080/api/channels/health     # 期望各字段如下
```

期望 health 变成：`"configured": true, "mode": "adapter", "reason": "", "card_action": true`
（口径在 `web/app.py:1473-1486`）。

## 4. 飞书开发者后台

1. 事件订阅 → 请求地址：`https://speeches-plant-confidence-constantly.trycloudflare.com/api/im/feishu`
   （路由在 `web/app.py:1498`，免登录但**必须**验签 + 时间戳 ±5 分钟）
2. 加密策略选「加密」，Encrypt Key / Verification Token 与 `.env` 填**同一个值**，否则 `verify()` 直接 401
3. 订阅事件：`im.message.receive_v1`（收消息）、`card.action.trigger`（卡片按钮回调）
4. 机器人能力里开启「接收消息」，并把应用发布到可用范围

## 5. 绑定真实 open_id（仓库暂无 HTTP 入口）

`channel_identities` 是 fail-closed 的唯一放行依据（`web/app.py:1535-1549`），未绑定直接 401 `identity_unbound`。
前端只展示「渠道绑定 N 个」计数，**没有发码 / 绑定的后端接口**，只能手工写库。

取 open_id：给机器人发一条消息，在飞书后台「事件订阅 → 调试台」的原始报文里看 `event.sender.sender_id.open_id`。

```bash
docker exec aib-api-1 python -c "import sqlite3;c=sqlite3.connect('/app/runtime/copilot.db');c.execute(\"INSERT INTO channel_identities VALUES ('feishu','ou_你的open_id','u_demo','2026-10-29T00:00:00+00:00')\");c.commit();print(c.execute('select * from channel_identities').fetchall())"
```

`bound_at` 用 ISO8601（现网那条是 `2026-10-28T15:40:31.866850+00:00` 这个格式）。

## 6. 验收

| # | 操作 | 期望 |
|---|---|---|
| 1 | 飞书里发「查余额」 | 200 + GREEN 计划卡，`QUERY_ONLY` |
| 2 | 发「转给李娜 500 元」 | YELLOW 计划卡 + `确认办理` 按钮（`value.action=confirm`） |
| 3 | 点「确认办理」 | 走 `card.action.trigger`，卡片回填执行结果 |
| 4 | 同一 `event_id` 重投 | `replayed: true`，不重复执行业务 |
| 5 | 未绑定账号发消息 | 401 `identity_unbound` |

也可用 `scripts/replay_webhook.py` 跑四项（`normal` / `tamper` / `replay` / `burst`），但 adapter 模式下
`--key` 必须换成**真实 Encrypt Key**，且 `AIB_FEISHU_REPLAY_USER` 要设成已绑定的 open_id，否则 normal 会撞 401。

## 7. 域名风险

trycloudflare 快速隧道域名不固定：`aib-tunnel` **一旦重启，回调地址立即失效**，飞书后台要同步改。
日常更新只重建 api（`up -d --build api`），不动 `aib-tunnel`，地址就不会变。

## 8. 回滚

删掉 `.env` 与 `docker-compose.yml` 里的四行 → 按第 3 步重建 → 回到 `mode=replay`，接口行为与现在一致。
