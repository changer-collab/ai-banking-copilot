# 飞书接入配置单

服务器只由组长写入以下环境变量：

```text
AIB_FEISHU_APP_ID=<私发>
AIB_FEISHU_APP_SECRET=<私发>
AIB_FEISHU_VERIFICATION_TOKEN=<私发>
AIB_FEISHU_ENCRYPT_KEY=<私发>
```

生产健康接口应返回：

```json
{
  "channels": {
    "feishu": {"configured": true, "mode": "adapter"}
  }
}
```

配置完成后再在飞书后台填写当天回调地址，并订阅 `im.message.receive_v1`。回调先验签、解密、事件幂等，再进入统一会话 Dispatcher；出站交互卡片失败只重试超时和 5xx，最多三次。
