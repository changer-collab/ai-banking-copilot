# 验收记录 · 尹辰 · 2026-10-27

> 三行摘要
> **改了什么**：Web 渠道加登录与多用户隔离（`AuthService` + `current_user` 依赖）、左栏对话历史（可点开恢复、单条删除）、生活事件面板、回答生成前的阶段步进器、`/im` 本地联调页骨架；并把第二演示用户（林静）独立播种进同一份库。

> **本记录的诚实边界**：只写**实际跑过**的东西。没有浏览器截图、没有公网手工点验，均单列在 §7，不当作已完成。

## 6. 怎么跑（部署 / 复核口径）

```powershell
$env:AIB_AUTH_MODE = "demo"          # 不设 = off（单用户演示，兼容旧基线）
$env:AIB_DEMO_PASSWORD = "aib-demo-1027"   # 不设则用同名默认值
python -m ai_banking_copilot.web          # 入口见公网 Demo 部署单
```

| 项 | 值 |
|---|---|
| 演示账号 | `chenming`（陈明 / `u_demo`）、`linjing`（林静 / `u_lin`），同一口令 |
| 主用户数据 | `transactions` 覆盖 `2025-01 .. 2026-09`，2026 年为 2025 年的 117.65% |
| 第二用户数据 | 覆盖 `2025-10 .. 2026-09`（12 个完整月），主键全部 `*_b_*` 前缀 |
| 会话 Cookie | `aib_session`，`HttpOnly` + `SameSite=Lax`，空闲 60 分钟到期（临期自动续期） |
| 快照保留 | 退出登录 / 换账号**不删**快照（支撑「重登后回看历史」）；只有「删除会话」才同时删消息 + 快照 + 清内存会话 |
| 删除二次验证 | `POST /api/auth/reverify` 换一次性票据（5 分钟），走 `X-Reverify-Ticket` 请求头 |

## 7. 还没做完 / 已知不足（不藏）

1. **截图没采**：`docs/2026-10-27/截图/尹辰/` 为空；登录页、个人中心、左栏历史、生活事件面板、步进器均无截图佐证。
2. **页面未做浏览器点验**：本轮验收只有接口级 + 单测级证据，没有在真实浏览器里逐页点过。
3. **生活事件面板没有逐卡参数表单**：七张卡可点、示例话术可一键发起（走 `/api/submit`），但「金额 / 日期 / 对象」表单没做；L1 / L3 / L4 的示例会先落到服务端澄清（缺商户 / 卡片 / 理财产品或额度），需要在对话里补一句。要补表单得同时改规划层槽位（`planning/slots.py`），属 D2 agent 重心。
4. **「缺信息」样本退化**：模板通道下「给我妈转点钱」落「未知意图 → 安全拒绝」，不是追问；原因不在本轮改动（意图识别属规划层），需要 LLM 通道或补亲属称谓模板才能满足交付清单里「AI 追问」那一类。
5. **「该拒绝」样本理由不准**：「直接转 5 万给张三，别确认」也是被意图识别挡下，没走到「绕过确认」的规则；结果对、归因不对。
6. **飞书未接**：`POST /api/im/feishu` 如实返回 501 `feishu_adapter_not_integrated`；`/im` 只是本地联调页，不参与产品验收。
7. **无真实账号体系**：预置 2 个账号，不做注册、不做改密。
8. **合并前状态**：改动已提交到 `feat/yinchen` 并推送，PR 见 §9；**尚未合并进 `sprint/1026`**，合并后需重跑一次全量并回填 `RESULTS.md` 基线。
