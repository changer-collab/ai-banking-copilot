# ai-banking-copilot · 项目规则（常驻硬约束）

> 本文件每次对话都会注入，只写「必须」和「禁止」；具体步骤在技能 `scene-workflow`。
> 与仓库既有约束的关系：安全与门禁以 `AGENTS.md` 为准，流程与分工以本文件为准。

## 1. 开工前

0. 确认已拉取主仓最新 `.trae/`（安装步骤见 `docs/2026-10-27/工作流安装指南-2026-10-27.md`）。规则没生效的表现是：agent 不知道你是谁、上来就改别人的文件。
1. **开场只说「我是谁」就够了**：例如「我是高靖雯，做转账」。**不用报工位、不用报场景编号**——场景编号和当前该做哪一步，由 agent 读代码自己判断；判断不出来就先问一句。
2. **一次对话说过一次就不用再说**：同一对话里后续不必重复报名字；换新对话或换了人用时再说一次即可。
3. 涉及场景功能的改动，先加载技能 `scene-workflow`（`.trae/skills/scene-workflow/SKILL.md`），按其中 S0–S7 的顺序推进；**一次只推进一件事**，做完再下一件，禁止「帮我把整个场景完善一下」式的批量改动。
4. 不知道自己是谁、也不知道该改哪些文件时，默认动作是「只读不改，先输出本场景现状地图」。

## 2. 文件权限（冲刺期 10/26–11/01 临时收紧）

- **仅尹辰可改**：`tools/catalog.py`、`policy/**`、`planning/kernel.py`。
  （`AGENTS.md` 允许 `catalog.py`、`policy/pdp.py` 按域分段改；冲刺期收紧，其他人一律发申请卡。）
- **可自行修改**：本人场景的 `scenarios/*.py`、对应的 `web/` 路由与前端场景块、对应的 `tests/`。
- **先申请再改**：`web/app.py`（按路由认领）、`web/assets/app.js`（按场景块认领）、`README.md`、`docs/*.md`。
- **禁止改动**：`contracts/`、`policy/audit.py` 的哈希算法、`policy/gate.py` 的判据、`policy/pep.py` 的三条硬约束、既有测试的语义断言（见 `AGENTS.md` 第 4 节）。

## 3. 变更申请卡

要改共享文件或内核时，先输出 5 行、等人工确认后再动手：

```
改什么：
为什么：
影响谁：
怎么回滚：
要不要结对：
```

## 4. 测试先行

- 后端实现（S4）一律**先写测试再实现**；D6 七条考题（3 主路径 + 3 刁钻 + 1 超范围）必须先落进 `eval/data/` 或 `tests/`。
- 禁止为了让测试变绿而放宽断言、删除对抗样例、绕过 PDP。

## 5. 收工标准

- 必须贴两样：**全量测试输出** + **变更摘要**（改了什么 / 为什么 / 动了哪些共享文件 / 需要谁配合）。只回「已完成」视为未交付。
- 门禁：`ruff check .`、`mypy`（strict）、`pytest` 全绿；涉及服务或页面另跑 `scripts/check_served_page.py`、`scripts/e2e_check.py`、`scripts/check_design_sync.py`。
- 没跑通不得声称完成。

## 6. 诚实性红线

- 不得在界面、文案、文档、PPT 里宣称未实现的能力；占位必须标注「演示 / 模拟 / 能力子集」。
- 不得编造执行结果；未核实的状态如实报 `committed_unverified`。
- 熔断只加严不降级；不得用 `AIB_DISABLE_LLM=1` 的结果冒充「AI 部分已实现」。

## 7. 数字与口径

- 任何对外数字必须能用命令复现，并写进 `docs/RESULTS.md` 的口径表；口径变化单独记一行「口径变更」。
- 仓库内数字必须三处一致：动作数（25）、Web 路由数、评测集条数。

## 8. 不做的事

- 不新增业务动作（当前 25 个已够）、不重写架构、不引入第三方依赖、不接真实生产支付 / 真实 IM 生产环境。
- 确需新增业务动作时，**六处必须同时补齐**（漏一处必红，详见 `AGENTS.md` 第 2 节）：
  ① `tools/catalog.py` 的 `ToolSpec`；② 本场景 `WRITE_HANDLERS` / `QUERY_HANDLERS` 的 handler；
  ③ `gateway/core_bank.py` 写原语；④ `policy/pdp.py` 三色口径；⑤ `planning/llm.py` 模板规则（新槽位另加 `planning/slots.py`）；
  ⑥ `eval/data/*.json` 用例 + `web/plan_card.py` 动作中文名。
- 不扩范围：只做本场景的 D1–D8，不顺手重构别人的模块。
